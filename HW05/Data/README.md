# Data

Datasets are public and downloaded automatically by `Code/data.py` (Hugging Face `datasets`, cached in `Data/hf_cache/`, not committed).

| Quiz | Dataset | Hugging Face ID | Original source |
| :--- | :--- | :--- | :--- |
| Quiz 1 Image Retrieval | CUB-200-2011 (Wah et al., 2011), 11,788 images, 200 bird species | [`bentrevett/caltech-ucsd-birds-200-2011`](https://huggingface.co/datasets/bentrevett/caltech-ucsd-birds-200-2011) | <https://www.vision.caltech.edu/datasets/cub_200_2011/> |
| Quiz 2 Multimodal Classification / Quiz 3 CLIP Captioning | Flickr8k (Hodosh et al., 2013), same split as Week 4 | [`jxie/flickr8k`](https://huggingface.co/datasets/jxie/flickr8k) | <https://hockenmaier.cs.illinois.edu/8k-pictures.html> |

Files in this folder:
- `week4_test_metrics.csv`, `week4_test_captions.csv`, `quiz4_cnn_*.json`: Week 4 results copied from `HW04/Output` and `HW04/Checkpoints` (the baseline that Quiz 3 is compared with; the JSONs hold the Week 4 per-epoch train/val loss and val BLEU-4).
- `q2_features_*.pt`, `q3_clip_tokens_*.pt`: cached frozen-backbone features generated by Quiz 2 / Quiz 3 (not committed).
