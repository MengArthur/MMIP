# Data

All datasets are public and are downloaded automatically by `Code/data.py` with the Hugging Face `datasets` library (cached in `Data/hf_cache/`, not committed to git).

| Quiz | Dataset | Hugging Face ID | Original source |
| :--- | :--- | :--- | :--- |
| Quiz 2 Sentiment Analysis | IMDB Large Movie Review Dataset (Maas et al., 2011) | [`stanfordnlp/imdb`](https://huggingface.co/datasets/stanfordnlp/imdb) | <https://ai.stanford.edu/~amaas/data/sentiment/> |
| Quiz 3 Image Classification | Oxford-IIIT Pet Dataset (Parkhi et al., 2012) | [`timm/oxford-iiit-pet`](https://huggingface.co/datasets/timm/oxford-iiit-pet) | <https://www.robots.ox.ac.uk/~vgg/data/pets/> |
| Quiz 4 Image Captioning | Flickr8k (Hodosh et al., 2013) | [`jxie/flickr8k`](https://huggingface.co/datasets/jxie/flickr8k) | <https://hockenmaier.cs.illinois.edu/8k-pictures.html> |

`Data/flickr8k_*_resnet50.pt` are cached ResNet-50 image features generated by Quiz 4 (also not committed).
